# DecodeLabs Java Projects

## Project 1: Number Guessing Game (`DecodeLabs_Java_P1.java`)
A fun and interactive game where the computer selects a random number between 1 and 100, and the player tries to guess it.

**Features:**
* Dynamic hints ("Too High!" or "Too Low!").
* Score tracking (starts at 100, decreases by 5 for each wrong guess).
* Robust input validation to prevent crashes from non-integers and out-of-bound guesses.
* Option to play multiple rounds.

## Project 2: Student Grade Calculator (`DecodeLabs_Java_P2.java`)
A utility program that calculates a student's total marks, average percentage, and final grade based on their input.

**Features:**
* Accepts a dynamic number of subjects.
* Validates marks to ensure they are within the valid 0-100 range.
* Calculates and displays Total Marks, Average Percentage, Letter Grade (A-F), and Pass/Fail status.
